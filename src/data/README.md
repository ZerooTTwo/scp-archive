# 静态内容（src/data）

这里放不需要联网、直接打包进 App 的展示数据。

| 文件 | 内容 |
| --- | --- |
| `taskforces.ts` | 六支机动特遣队的名称、代号、格言、职责、驻地、所需权限、行动记录、装备和人员名录 |

## 说明

- 特遣队内容是**同人阅读体验**，不是 SCP 基金会官方编制。
- 权限过滤在 `src/pages/Taskforces.tsx`：O5/4 级看完整档案，3 级只看名录，1 级和 D 级锁定。
- 新增单位时保持 `clearance` 字段为 `'o5' | 'l4' | 'l3'`，页面会自动按等级过滤。
